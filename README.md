# Кастрюля (AI Meal Planner)

> 🚧 Проект в активной разработке, возможны изменения и нестабильная работа.

MVP-приложение, которое подбирает план питания на несколько дней 
под заданный бюджет. Указываете сумму, срок и количество человек — 
получаете готовый план с блюдами, ингредиентами и примерными ценами, 
без необходимости самому придумывать, что приготовить.
