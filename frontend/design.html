05
Layout и адаптив
Брейкпоинты
base < 768px — мобильный, одна колонка
md ≥ 768px — планшет: форма в одну колонку по центру (max-w 620), план — дни в 2 колонки приёмов
lg ≥ 1024px — десктоп: двухколоночные экраны
xl ≥ 1280px — контейнер max-w 1344, поля 48px
Экран формы
Десктоп (lg+): `grid grid-cols-[1fr_620px] gap-16 px-12 pt-14` — слева оффер (заголовок 66px, описание, 2 метрики в ряд flex gap-10), справа панель формы. Панель: `bg-surface border rounded-3xl p-9 flex flex-col gap-6`. Внутри — 4 группы: бюджет, [дней | человек] `flex gap-4`, разнообразие `grid grid-cols-3 gap-2.5`, кнопка + сноска `flex items-center gap-4`. Экран не скроллится: суммарная высота ≤ 860.

Мобильный (base): одна колонка `flex flex-col gap-5 px-5 pt-6 pb-5`, заголовок 36px, разнообразие — вертикальный список строк, кнопка прижата вниз через `mt-auto`, safe-area-inset-bottom учитывается.
Экран результата
Десктоп (lg+): шапка-бар (лого, параметры плана, «Список покупок») + `grid grid-cols-[1fr_380px] gap-10 px-12 py-9 items-start`. Левая колонка — стек карточек дней `flex flex-col gap-3.5`; развёрнутый день раскладывает приёмы пищи в `grid grid-cols-3 gap-7`. Правая — `sticky top-6` с TotalPanel, метриками и подсказкой.

Мобильный (base): TotalPanel закреплён сверху (`sticky top-0`), список дней скроллится, действия — в нижней панели `sticky bottom-0` с `flex gap-2.5` (пропорции 1 : 1.4). Приёмы пищи — вертикальный стек, gap 14.
Правила выравнивания
· Любая пара «название — цена» строится как `flex justify-between items-baseline`, цена прижата вправо, tabular-nums.
· Группы кнопок и полей — только flex/grid + gap, никаких margin между соседями.
· Все интерактивные зоны на мобильном ≥ 44×44px.
· Максимальная ширина абзаца текста — 62ch.
· Один экран = один акцентный элемент максимальной яркости (сумма). Остальное — нейтральное.

Логотип
Кастрюля
16px — favicon, читается
На тёмном фоне знак используется без изменений — терракотовая плашка сама создаёт контраст. Инверсия и обводка не нужны.
Правила
· Файл: logo.svg, viewBox 0 0 64 64, плашка #C4623F (radius 16 при 64px = 25%), знак #F3EDE4.
· Размеры в интерфейсе: 24px (моб. шапка) · 28–30px (десктоп-шапка) · 48px (документы) · 16/32/180px для favicon и apple-touch-icon.
· Радиус скругления плашки масштабируется пропорционально (25% от размера); при 16px допустимо 4px.
· Минимальное защитное поле вокруг знака — 25% его размера. Логотип не растягивать, цвета плашки не менять, тени не добавлять.
· Словесная часть «Кастрюля» — Newsreader 400, идёт справа от знака с отступом 10–12px, выравнивание по оптическому центру.
07
Чек-лист вёрстки
Подключены Newsreader (300/400/500) и Karla (400/500/600), задан font-display: swap
Токены цветов вынесены в tailwind.config, хардкод hex в JSX отсутствует
Все суммы — tabular-nums, разделитель тысяч — неразрывный пробел
У каждого интерактивного элемента реализованы hover / active / focus-visible / disabled
Focus-ring #C4623F виден при навигации с клавиатуры, порядок Tab логичен
Аккордеон дня: button + aria-expanded + aria-controls, работает Enter/Space
Итоговая сумма видна без скролла на обоих брейкпоинтах
Реализованы состояния экрана: loading (скелетоны дней), empty, error, превышение бюджета
Хит-зоны на мобильном ≥ 44px, учтён safe-area-inset-bottom
Анимации ≤ 220ms, все выключаются при prefers-reduced-motion
Контраст текста ≥ 4.5:1 (проверить #8A7B6C на #F3EDE4 — только для 12px+ метаданных)
Длинные названия блюд и ингредиентов не ломают верстку (text-wrap: pretty, min-w-0)
